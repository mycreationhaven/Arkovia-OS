## Required checks

- Live USB boot
- Installer launch and completed installation on an expendable test disk
- Wired and wireless networking
- Audio input and output
- Display resolution, brightness, sleep, and resume
- USB storage
- Printing and scanning where available
- Update and restart
- Idle memory and boot time
- Browser responsiveness under the documented light workload
- Recovery procedure
