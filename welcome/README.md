# Arkovia Welcome Center

The Welcome Center will guide nontechnical users through:

- Updates
- Wi-Fi and networking
- Printers and scanners
- Applications and setup profiles
- Desktop layout and appearance
- Accessibility
- Backup and recovery
- Privacy choices
- Old-PC Performance Mode
- Help and issue reporting

The implementation language and toolkit will be selected after the first ISO
proves the base desktop and installer path.
