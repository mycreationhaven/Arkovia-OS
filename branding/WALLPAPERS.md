# Arkovia OS wallpaper themes

Arkovia OS includes four calm, colorful 1920x1080 wallpapers created for this
project. Ocean Wildlife is the initial desktop and login-screen background.

| Theme | File |
| --- | --- |
| Ocean Wildlife | `theme-ocean-wildlife.jpg` |
| Space | `theme-space.jpg` |
| Forest Wildlife | `theme-forest-wildlife.jpg` |
| Around the World | `theme-around-the-world.jpg` |

All wallpapers are stored under `/usr/share/backgrounds/arkovia/` in the live
system. They contain no text or logos so desktop icons remain readable and the
images work across homes, businesses, churches, and family computers.
