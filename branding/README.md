# Branding

This directory documents Arkovia OS-owned visual assets and their source
requirements. The current image includes:

- Primary and monochrome logos
- An animated Arkovia Plymouth boot theme
- Arkovia-branded BIOS and UEFI boot menus
- An Arkovia login-screen treatment
- Four 1920x1080 desktop wallpaper themes: Ocean Wildlife, Space, Forest
  Wildlife, and Around the World
- Light, dark, and high-contrast theme specifications
- Application icon and color guidance

Do not add third-party artwork or fonts without verified redistribution rights.
The current wallpaper collection was generated specifically for the Arkovia OS
project and contains no third-party logos or supplied artwork.
