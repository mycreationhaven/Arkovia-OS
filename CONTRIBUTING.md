# Contributing to Arkovia OS

Thank you for helping make computing more accessible to homes, families,
businesses, churches, schools, and communities.

## Before contributing

1. Search existing issues before opening a new one.
2. Keep each issue or pull request focused on one change.
3. Do not include copyrighted artwork, fonts, firmware, or code without clear
   redistribution permission.
4. Never commit passwords, signing keys, tokens, private customer information,
   or hardware serial numbers.
5. Test user-facing changes at the 2 GB memory target when practical.

## Pull requests

- Explain the user problem and the proposed result.
- List the tests performed.
- Note any accessibility, performance, security, or licensing impact.
- Update documentation when behavior changes.
- Preserve the principle that profiles customize one Arkovia OS rather than
  creating separately branded editions.

## Commit style

Use concise, imperative commit subjects, for example:

```text
Add minimal profile package list
Document legacy BIOS test procedure
Fix Welcome Center keyboard navigation
```

## Current licensing limitation

The project has not finalized its open-source license or contributor agreement.
By submitting a contribution, you affirm that you have the right to submit it,
but maintainers may postpone merging substantial original code until the
project's contribution terms are finalized.
