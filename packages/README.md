# Arkovia packages

This directory is reserved for packaging metadata and source for original
Arkovia OS components. Likely initial packages include:

- `arkovia-defaults`
- `arkovia-branding`
- `arkovia-welcome`
- `arkovia-profile-home`
- `arkovia-profile-business`
- `arkovia-profile-church`
- `arkovia-profile-education`
- `arkovia-profile-minimal`

Each package must document its license, source, dependencies, and upgrade
behavior before entering a release image.
